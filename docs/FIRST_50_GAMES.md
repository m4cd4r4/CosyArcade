# CosyArcade — First 50 Games Content Strategy

This document outlines the initial game library for CosyArcade launch. All games must be **legally free** (homebrew, freeware, or open source).

---

## Selection Criteria

Every game must meet ALL of these requirements:

- [ ] **Legal**: Homebrew, freeware, open source, or public domain
- [ ] **Documented**: Source/licence clearly documented
- [ ] **Working**: Tested and functional in EmulatorJS
- [ ] **Quality**: Enjoyable gameplay, not just technically impressive
- [ ] **Age-Rated**: Appropriate rating assigned (ALL or TEEN_13)

## Priority Order for Launch

### Phase 1: Core Library (20 games)
Focus on games that are:
- 100% confirmed legal
- Working perfectly in EmulatorJS
- High quality and fun
- Mix of platforms

### Phase 2: Expanded Library (30 more games)
- Complete verification of remaining games
- Add more variety in genres
- Ensure good age rating distribution

### Phase 3: Ongoing Curation
- Community submissions
- New homebrew releases
- Quality over quantity always
